---
name: Applicant progress visibility
description: The enrollment workflow must preserve applicant progress and limit reviewer access to authorized staff.
---

Persist full-application wizard answers and progress on the server as applicants save steps. Make those saved records visible only to authorized administrators and reviewers. Preserve the guest pre-application flow and its separate evidence-collection requirements.

**Why:** The user asked that every applicant's steps be saved for the authorized admin/reviewer.

**How to apply:** Keep applicant ownership checks on save and read routes, include in-progress applications in authorized review views, and do not expose draft answers to the public or unauthorized staff.
